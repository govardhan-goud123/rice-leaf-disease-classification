# Rice Leaf Disease Classification Using Deep Learning

## 📌 Project Overview

This project uses Deep Learning and Transfer Learning to classify rice leaf images into three different disease categories.

The objective is to develop an image classification model that can help identify common rice leaf diseases from leaf images.

## 🦠 Disease Classes

* Leaf Smut
* Brown Spot
* Bacterial Leaf Blight

## 🤖 Models Used

The following models were trained and compared:

* VGG16
* MobileNetV2
* EfficientNetB0

## 📊 Results

| Model          | Test Accuracy |
| -------------- | ------------: |
| VGG16          |        61.11% |
| MobileNetV2    |        88.89% |
| EfficientNetB0 |        33.33% |

**MobileNetV2 achieved the best test accuracy of 88.89%.**
